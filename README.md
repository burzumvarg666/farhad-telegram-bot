# Farhad Telegram AI Bot

FastAPI Telegram bot deployed on Vercel.

## Features
- Persian/English AI assistant with conversational personality
- Existing free-model routing and image-analysis path retained
- Reply keyboard with help, status, memory, games, and about
- Recent conversation memory (Supabase-backed when configured, in-process fallback otherwise)
- Quiz and word-riddle games with cumulative scorekeeping

## Commands
- `/start` show menu
- `/help` help
- `/status` service status
- `/memory` memory status
- `/reset` clear this chat's conversation memory
- `/about` bot info
- `/games` open games
- `/quiz` start quiz
- `/riddle` start riddle

## Enable persistent memory and scores
Create a Supabase project. In its SQL Editor, run:

```sql
create table if not exists public.bot_memory (
 id bigint generated by default as identity primary key,
 chat_id bigint not null,
 role text not null check (role in ('user','assistant')),
 content text not null,
 created_at timestamptz not null default now()
);
create index if not exists bot_memory_chat_created_idx on public.bot_memory (chat_id, created_at desc);
create table if not exists public.bot_game_scores (
 chat_id bigint primary key,
 score integer not null default 0 check (score >= 0),
 updated_at timestamptz not null default now()
);
```

In Vercel Project Settings → Environment Variables, add `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` for Production (and Preview if needed), then redeploy. Get both from Supabase Project Settings → API. Keep the service-role key private; never commit it or put it in frontend code. Check `/health`: `memory_persistent_configured` should be true. Without these settings, memory remains temporary. `/reset` deletes the chat's stored memory when Supabase is configured.

## Environment variables
- `TELEGRAM_BOT_TOKEN` (or `TELEGRAM_TOKEN`)
- `TOKENHARBOR_API_KEY` (or legacy `ZAI_API_KEY`)
- `GEMINI_API_KEY`
- `GROQ_API_KEY`
- `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` for persistent storage
- Optional: `GEMINI_MODEL`, `DEEPSEEK_FAST_MODEL`, `DEEPSEEK_MODEL`, `GROQ_MODEL`, `GROQ_FALLBACK`

## Tests
Run `python -m unittest discover -s tests -v`. A health check alone does not prove provider, image, database, and game flows all work end-to-end.
